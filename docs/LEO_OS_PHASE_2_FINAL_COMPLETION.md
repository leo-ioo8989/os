## Final operating chain

```text
OWNER INTENT
  → LEO EXECUTIVE / GOVERNED INTELLIGENCE
  → PLAN + CAPABILITY REQUIREMENTS
  → WORKFORCE / PROVIDER ELIGIBILITY
  → DELEGATION PROPOSAL
  → EXISTING DURABLE JOB / DISPATCH / WORKER RUNTIME / EXECUTION GATEWAY
  → VALIDATED RESULT
  → OUTCOME EVALUATION
  → EXECUTIVE CONTINUATION
  → DURABLE EXECUTIVE HISTORY
  → GOVERNED OPERATING EVENT
  → EXTERNAL ACTION / PROACTIVE WORK / SPEND PROPOSAL
  → EXISTING CONTROL PLANE
```

The final three proposal boundaries do not execute external actions, schedule work, purchase anything, grant approvals, access credentials, create workers, or bypass the Phase 1 control plane.

## Stress certification

The Phase 2 completion branch contains a deterministic matrix of **20,480 genuinely varied owner prompts**:

`32 domains × 8 task forms × 8 contexts × 10 semantic variants = 20,480`

The matrix checks:

- intent acceptance;
- deterministic capability inference;
- proposal generation;
- organization binding;
- risk semantics;
- approval-required semantics;
- task-graph validation;
- authority-field non-leakage;
- unknown/ambiguous prompt behavior;
- critical-risk preservation.

The matrix is generated at test time rather than storing a giant static prompt file, so the suite remains reviewable and deterministic.

## Phase 2 non-negotiable invariants

- CONTROL PLANE > AGENT
- POLICY > MODEL OUTPUT
- APPROVAL > AGENT INTENT
- AUDIT > ASSUMPTION
- DURABILITY > IN-MEMORY STATE
- EXPLICIT AUTHORITY > IMPLICIT TRUST
- FAIL CLOSED FOR HIGH-RISK ACTIONS
- MEMORY = CONTEXT, NOT AUTHORITY
- MODEL OUTPUT = UNTRUSTED DATA
- PROPOSAL ≠ EXECUTION
- APPROVAL REQUIRED ≠ APPROVAL GRANTED
- CAPABILITY REQUIREMENT ≠ CAPABILITY GRANT
- PROVIDER/MODEL SELECTION ≠ WORKER AUTHORIZATION

## Completion gate

Phase 2 is complete only when the certification workflow is terminal `SUCCESS` on the final head and the stress matrix passes with zero failures.

No green claim is valid from a partial, queued, cancelled, or superseded run.
