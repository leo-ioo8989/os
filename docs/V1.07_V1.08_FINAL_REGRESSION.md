## 11. Remaining limitations

1. Exhaustive HTTP status permutations across every route were not independently enumerated.
2. Exhaustive cross-organization permutations for every resource/API route were not independently enumerated.
3. Process interruption was tested with real process termination, but not at every possible instruction boundary.
4. PostgreSQL CI uses `POSTGRES_HOST_AUTH_METHOD=trust` only inside the disposable isolated CI service.
5. This is a regression certification of V1.07/V1.08 in the current implementation, not a mathematical proof over every possible input.
