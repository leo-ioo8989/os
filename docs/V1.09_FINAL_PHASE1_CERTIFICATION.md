## Evidence policy

`IMPLEMENTED` means source changes exist.
`RUNTIME VERIFIED` means an executable test/CI path actually exercised the behavior.
`PARTIALLY VERIFIED` means only part of the requested scenario was exercised.
`NOT VERIFIED` means no qualifying runtime evidence exists.
`BLOCKED` means the environment prevented execution.

No capability is certified solely because its source code exists.
